Тема: Агрегированные TAG для production

Коллеги, привет!

Передаю файлы для расчёта агрегированных TAG:

- fit_and_save_agg_scalers.ipynb
- prod_agg_transform.ipynb
- aggregated_tags_pipeline.pkl
- config.py

fit_and_save_agg_scalers.ipynb нужен для подготовки артефакта. Он рассчитывает сырые скоры, настраивает MinMaxScaler для каждой группы и сохраняет параметры в aggregated_tags_pipeline.pkl. Также он сохраняет рассчитанные признаки в CSV.

Этот ноутбук уже был запущен на исходном датасете. Для новых котировок повторно запускать его не нужно. Config.py нужен только для повторной подготовки pkl.

prod_agg_transform.ipynb используется для новых данных. Он загружает готовый pkl, проверяет наличие обязательных TAG, рассчитывает сырые скоры и применяет сохранённые MinMaxScaler.

Перед production-запуском нужно указать путь к новым данным в ячейке «Новые данные» файла prod_agg_transform.ipynb:

DATA_CSV_PATH = r"путь_к_файлу"

Файл pkl по умолчанию должен лежать здесь:

artifacts/model/aggregated_tags_pipeline.pkl

Если файл лежит в другом месте, нужно изменить MODEL_PATH в production-ноутбуке.

Для новых котировок нужны только prod_agg_transform.ipynb и aggregated_tags_pipeline.pkl. Config.py для production-расчёта не используется. Все ячейки выполняются по порядку.

На выходе получается DataFrame result с тремя признаками:

- auto_lover_agg_coef
- shopping_agg_coef
- alcohol_agg_coef

Договоры без заполненных TAG в результат не попадают. Если обязательного TAG нет во входном файле, расчёт остановится и покажет список отсутствующих колонок.

Значения ниже диапазона исходной выборки приводятся к 0. Значения выше диапазона приводятся к 1.

Для запуска нужны pandas и scikit-learn. Желательно использовать ту же версию scikit-learn, на которой был создан pkl.
