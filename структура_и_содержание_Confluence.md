## Как собирается датасет

### Основная цепочка Сферы

```text
bps_contract
→ bps_request_ins
→ bps_request_ins_task
→ bps_request_ins_task_insurance_object
→ base_insurance_object_characteristics
→ base_insurance_object
→ base_geo_address
→ base_insurance_object_conditions
```

Одна строка датасета соответствует одному объекту недвижимости. Если объект связан с несколькими договорами, для каждого договора создаётся отдельная строка.

В расширенный датасет также попадают объекты, для которых не найдена официальная связь с договором. В таких строках договорные поля остаются пустыми.

### Условия отбора связанных договоров

- `task_type = 'draft_contract'` — оформление договора;
- `status = 'operational_archive'` — завершённая рабочая задача;
- `ins_document_type = 'new_ins_contract'` — новый договор;
- `ins_document_type = 'ins_contract_prolong'` — пролонгация;
- также допускается незаполненный `ins_document_type`;
- `ins_refuse IS NOT TRUE` — отказ в страховании не установлен;
- `d_delete IS NULL` — удалённые записи исключаются;
- `elementary_obj_type = 'nedv_ul_and_ip'` — недвижимость ЮЛ и ИП.

Если для договора найдено несколько подходящих задач, используется последняя.

## Соединение с CDI и ЕГРН

```text
full_address из Сферы
→ DM_MOTOR.F_GET_CDI_ADDR_BY_TEXT
→ FIAS_ID_HOUSE
→ DM_RISK_AVATAR.EGRN_DATA
→ одно найденное здание
```

Данные ЕГРН присоединяются только при одном найденном здании. Если найдено несколько кандидатов, поля ЕГРН остаются пустыми.

Из ЕГРН доступны, в частности:

- площадь здания;
- назначение и тип здания;
- материал стен;
- этажность;
- год ввода;
- кадастровая стоимость `EGRN_DATA.PRICE`;
- стоимость квадратного метра `EGRN_DATA.SQUARE_METER_PRICE`;
- координаты.

## Статистика признаков

Собран статистический паспорт всех доступных полей Сферы, CDI и ЕГРН.

Для каждой колонки указаны:

- источник и исходная таблица;
- описание;
- тип данных;
- количество заполненных и пустых строк;
- процент заполнения;
- количество уникальных значений;
- основные числовые статистики.

Пустые строки, `NULL`, `{}` и `[]` не считаются заполненными значениями.

По предварительной проверке:

- 309 колонок полностью пустые;
- около 147 колонок содержат одно значение;
- есть повторяющиеся и технические поля;
- часть полей требует проверки на утечку целевой переменной.

Поля также разделены по назначению:

- целевая переменная;
- потенциальный признак модели;
- вспомогательный признак;
- идентификатор для связи и контроля;
- служебное поле;
- поле для разделения train/test.

## Ограничения

- для части объектов не найдена официальная связь с договором;
- адрес заполнен не для всех объектов;
- не для каждого адреса CDI возвращает один ФИАС дома;
- одному ФИАС могут соответствовать несколько зданий ЕГРН;
- некоторые характеристики объектов заполнены редко;
- координаты требуют проверки;
- текущие данные ЕГРН могли быть обновлены позже даты договора;
- технические ID, ИНН, ФИАС, кадастровые номера и полные адреса не передаются в модель как обычные признаки.
