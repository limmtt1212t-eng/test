Датасет

Из Сферы собран датасет по объектам недвижимости. Одна строка соответствует одному объекту недвижимости в одном договоре. Получено 1106 строк.

В датасет включены объекты, соответствующие следующим условиям:

- тип задачи: task_type = 'draft_contract', оформление договора;
- статус задачи: status = 'operational_archive', завершённая рабочая задача;
- тип документа: новый договор new_ins_contract, пролонгация ins_contract_prolong или незаполненное значение;
- тип объекта: elementary_obj_type = 'nedv_ul_and_ip', недвижимость.

Если для договора найдено несколько подходящих задач, используется последняя. Если объект несколько раз связан с задачей, используется последняя актуальная запись связи.

Целевая переменная

Целевая переменная модели — страховая сумма объекта:

base_insurance_object_conditions.insured_sum

Дополнительные источники

ДКС планирует подготовить парсеры для получения данных из внешних источников.

Геоаналитика

В дальнейшем рассматривается добавление геоаналитических признаков, например расстояния до ближайшей пожарной части.
